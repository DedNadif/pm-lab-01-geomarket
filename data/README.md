# Данные проекта

Здесь хранятся данные, используемые в проекте. Реестр источников с описанием и оценкой наборов данных находится в [sources.md](sources.md).

## Структура

| Папка | Что лежит | В репозитории? |
|---|---|---|
| `raw/` | Данные, полученные непосредственно из источников. Вручную не редактируются. | Нет, кроме `.gitkeep` |
| `manual/` | Таблицы, собранные вручную из публикаций. У каждой строки должны быть указаны год и ссылка на источник. | Да |
| `processed/` | Очищенные и подготовленные данные для анализа. | Да, если файл меньше 10 МБ |
| `sources.md` | Реестр источников данных. | Да |

Сырые данные не хранятся в Git, поскольку могут занимать много места и со временем обновляться. Способ их получения описан ниже, чтобы любой участник проекта мог повторить загрузку.

## Как получить данные

### OpenStreetMap (DS-01)

Для загрузки пространственных данных используется OpenStreetMap через библиотеку OSMnx и Overpass API.

Территория исследования — Антананариву, Мадагаскар. Для неё используется приближённая область радиусом 10 км вокруг геокодированного центра города. Это буфер для анализа, а не официальная административная граница.

**Порядок загрузки:**

1. Установить зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
2. Открыть `notebooks/01_data_collection.ipynb` в Google Colab или локальной среде Jupyter.
3. В ноутбуке проверить настройки территории исследования и путь к папке проекта (`PROJECT_FOLDER`, если используется Google Диск).
4. Выполнить ячейки ноутбука последовательно.
5. Дождаться завершения загрузки. Полученные GeoPackage-файлы сохраняются в `data/raw/`.
6. Проверить файл `data/raw/_download_log.json`: в нём записаны дата загрузки, источник, лицензия и количество объектов.

При работе в Google Colab необходимо подключить Google Диск и указать правильную папку проекта. При локальном запуске данные сохраняются в `data/raw/` внутри проекта.

**Полученные слои:**

| Файл | Содержимое | Объектов | Система координат |
|---|---|---:|---|
| `water_points.gpkg` | Точки и другие объекты, связанные с водными объектами | 224 | EPSG:4326 |
| `parks.gpkg` | Парки и зелёные территории | 32 | EPSG:4326 |
| `residential.gpkg` | Жилая застройка | 7155 | EPSG:4326 |
| `boundary.gpkg` | Буфер радиусом 10 км вокруг центра города | 1 | EPSG:4326 |
| `districts.gpkg` | Административные объекты для слоя районов | 0 | EPSG:4326 |

Дата загрузки: 20.11.2026.

**Ограничения:**
- `boundary.gpkg` представляет собой буфер вокруг геокодированного центра, а не официальную границу города.
- `districts.gpkg` создан, но остался пустым: подходящие объекты для выбранного уровня административного деления не найдены.
- Количество и состав объектов OpenStreetMap могут меняться при повторной загрузке.
- На текущем этапе собраны не все слои, необходимые для полного анализа: данные о кафе-конкурентах, дорогах и общественном транспорте ещё предстоит добавить.

## Слои в processed/

На текущем этапе подготовленные для анализа слои в `processed/` не сформированы. Результаты первичного сбора находятся в `raw/`.

После обработки данных в ноутбуке `02` здесь следует указать имена файлов, их содержание, источники, системы координат и количество объектов.
