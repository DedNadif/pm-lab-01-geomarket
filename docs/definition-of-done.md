# Definition of Ready и Definition of Done

## Definition of Ready — задача готова к работе

Задачу можно брать в работу, когда:

- [ ] Указаны цель и ожидаемый результат.
- [ ] Записаны проверяемые критерии готовности.
- [ ] Назначен ответственный.
- [ ] Известны необходимые исходные данные и доступ к ним, если они нужны.
- [ ] Известны зависимости от других задач и их состояние.
- [ ] Для пользовательской истории указаны эпик и приоритет MoSCoW.

## Definition of Done — задача выполнена

### Для любой задачи

- [ ] Выполнены критерии готовности, указанные в задаче.
- [ ] Документация обновлена, если изменения её затрагивают.
- [ ] Обязательные проверки PR прошли, если они настроены.
- [ ] Изменения связаны с задачей через PR, одобрены другим участником и влиты в `main`.

### Для задач с данными

- [ ] Для новых данных в `data/sources.md` указаны источник, лицензия и дата получения.
- [ ] Сырые данные не добавлены в Git.
- [ ] Изменённые ноутбуки выполнены сверху вниз без ошибок и сохранены без вывода ячеек.
- [ ] Расстояния и площади рассчитаны в метрической системе координат, если такие расчёты выполнялись.
- [ ] Для карт указаны легенда и источники, включая авторство OpenStreetMap, если используются его данные.

### Для пользовательских историй

- [ ] Проверены сценарии приёмки, указанные в истории.
