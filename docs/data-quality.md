|---|---|---|---|

| `parks` | Название / тематические атрибуты | Не зафиксировано | Требует проверки по выводу профиля |
| `residential` | Основные атрибуты объектов | Не зафиксировано | Требует проверки по выводу профиля |
| `districts` | Атрибуты районов | — | Слой пустой, атрибутный анализ невозможен |

## Найденные проблемы

| № | Проблема | Как обнаружена | Влияние на анализ | Решение | Issue |
|---|---|---|---|---|---|
| 1 | Пустой слой `districts` | Проверка количества объектов слоя показала 0 | Нельзя использовать районы для районного агрегирования и сравнения | Проверить источник и повторно получить слой районов либо исключить районный анализ | Создать Issue |
| 2 | Возможные дубликаты водных точек | Поиск соседей в радиусе 5 м: обнаружено 4 точки с близкими соседями | Возможен завышенный подсчёт точек; близкое расположение само по себе не доказывает дубликат | Проверить совпадение OSM ID и тегов; не удалять только по расстоянию без проверки | Создать Issue |
| 3 | Объекты вне границы исследования | Пространственная проверка пересечения с границей: water_points — 1, parks — 2, residential — 129 объектов вне территории | Объекты за пределами области могут искажать локальные подсчёты и визуализацию | В ноутбуке слои, кроме `districts`, фильтруются по пересечению с территорией | Создать Issue |
| 4 | Колодцы/скважины входят в слой водных точек | Проверка комбинаций тегов `amenity` и `man_made`; в очистке задано исключение `man_made=water_well` | Колодцы могут быть ошибочно интерпретированы как питьевые водные точки | Исключать объекты с `man_made=water_well` из очищенного слоя водных точек | Создать Issue |

## Правила очистки

| Правило | Почему | Сколько объектов затронуто | Согласовано с заказчиком |
|---|---|---|---|
| Удалить пустые геометрии | Такие объекты не участвуют в корректном пространственном анализе | Точное количество не сохранено | Требует подтверждения |
| Исправить некорректные геометрии с помощью `make_valid()` | Для предотвращения ошибок геометрических операций | Точное количество не сохранено | Требует подтверждения |
| Удалить повторные записи по `osm_type` и `osm_id` | Один OSM-объект не должен учитываться несколько раз | Точное количество не сохранено | Требует подтверждения |
| Оставить объекты, пересекающие территорию исследования (для слоёв кроме `districts`) | Сосредоточить анализ в пределах заданной области | Water points: 1 вне; parks: 2 вне; residential: 129 вне — по первичной проверке | Требует подтверждения |
| Исключить `man_made=water_well` из `water_points` | Колодцы и скважины не считать питьевыми точками в рамках принятого примера | Точное количество не сохранено | Требует подтверждения |
| Для `water_points` заменить геометрии представительной точкой (`representative_point()`) | Привести объекты к точечному представлению для анализа расстояний и карты | Число объектов после предыдущих операций не зафиксировано | Требует подтверждения |

## Проверка требований к данным

| Требование | Порог | Факт | Выполнено? |
|---|---|---|---|
| Наличие пространственных слоёв для анализа | Нужные слои должны быть доступны и содержать данные | `water_points`, `parks`, `residential` имеют объекты; `districts` пустой | Частично |
| Геометрии должны быть пригодны к пространственным операциям | Пустые геометрии удалены, некорректные исправлены | Очистка предусмотрена в ноутбуке; точные итоговые числа не сохранены | Требует подтверждения запуска |
| Дубликаты должны быть устранены | Уникальность по OSM ID | В ноутбуке предусмотрено удаление дубликатов по `osm_type` и `osm_id` | Требует подтверждения |
| Объекты должны относиться к территории анализа | Для слоёв, кроме `districts`, выполняется фильтрация пересечения с границей | За границей предварительно обнаружены 1 водная точка, 2 парка и 129 жилых объектов | Частично |
| Атрибуты должны быть достаточно заполнены для анализа | Заполненность ключевых полей должна быть проверена | Проценты не сохранены в приложенном выводе | Не подтверждено |

## Заключение об осуществимости

**Итог: достаточно с оговорками для демонстрации процедур профилирования и очистки исходных слоёв AquaMap.**

В исходных данных присутствуют слои водных точек, парков и жилых объектов, пригодные для проведения базовых пространственных проверок и дальнейшего учебного анализа после очистки. В ходе первичной проверки обнаружены пустой слой районов, близко расположенные водные точки, объекты за пределами территории и неоднозначность классификации водных объектов (в частности, колодцев/скважин).

В ноутбуке реализованы правила удаления пустых геометрий, исправления геометрий, устранения дубликатов по OSM ID, фильтрации объектов по границе и исключения колодцев из слоя водных точек. Однако точные итоговые количества после каждой операции и показатели заполненности атрибутов следует подтвердить повторным запуском и сохранением всех ячеек с выводами.

Перед использованием результатов в следующих этапах необходимо проверить пустой слой `districts`, подтвердить правила исключения объектов и завершить документирование фактических показателей качества. Этот отчёт описывает учебный набор AquaMap и не является оценкой данных проекта геомаркетинга кофейни.
