Протокол встречи: Интервью с заказчиком по проекту «Геомаркетинг: выбор точки для кофейни»
Дата: 30.10.2026 · Участники: Рафаэль К., Азат Г., Дмитрий К., Роман М., Заказчик (представитель сети кофеен) · Ведёт протокол: Азат Г.

**Повестка**
1. Уточнение бизнес-целей открытия новой точки в Антананариву.
2. Определение критериев «целевого клиента» и требований к локации.
3. Обсуждение доступных данных и ограничений по бюджету/срокам.

**Что обсудили и решили**
- **Цель:** Открытие точки с высокой проходимостью целевой аудитории (офисные сотрудники, студенты) в радиусе 5 км от центра Антананариву.
- **Критерии успеха:** Потенциальный ежедневный трафик не менее 500 человек, отсутствие прямых конкурентов в радиусе 300 метров.
- **Данные:** Заказчик предоставил исторические данные по продажам существующих точек для калибровки модели. Основной источник геоданных — OpenStreetMap.
- **Сроки:** Запуск MVP веб-карты необходим через 4 недели для презентации инвесторам.
- **Риски:** Возможны перебои с интернетом при сборе данных «в поле», что учтено в плане рисков.
